# Boolean Expression Simplification Dashboard

A Python-based dashboard built with **Streamlit** that automates the minimization of Boolean expressions using the **Quine-McCluskey Tabulation Method**.

## Features
- Interactive sidebar configuration for variable counts (2 to 6 variables).
- Custom minterm entry.
- Step-by-step breakdown of the Quine-McCluskey combination process.
- Clean Sum-of-Products (SOP) output representation.
